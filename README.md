# 阅兵 · Military Parade 1.0.0

首发版以3.20 B1为基础冻结玩法，移除屏幕调试标记与版本前缀；模组GUID不变，内部modinfo版本递增为25。

安装：仅将Release/MilitaryParade放入文明6的Mods目录。关闭游戏后替换旧版本。工坊订阅版本与手动安装版保持一份启用，避免同GUID重复。

发布：使用本包Workshop中的简介与preview.jpg，通过文明6Steam Workshop Uploader选择Release/MilitaryParade/MilitaryParade.modinfo。无需重新Build。详细步骤见顶层PUBLISH_zh_CN.txt。

规则：需要迭起兴衰或风云变幻，当前仅支持单人。完成帝国初期、当前首都中心有本国战斗单位才能生产。重复完成刷新十回合鼓舞，不叠加。基础成本60，随科技/市政进度增长，不随次数增长。将军在中心时仅阅兵生产力+50%，奖励提高一档。

首次时代分+2，此后每次合法完成+1；大将军点数按本国时代为5/10/20/35/50/70/90/120/150。军事分档位及效果详见工坊简介。

军事单位生产力+10%为生产加成中的10个百分点，不改变城市通用总产出，也不用于购买折扣。新训练、购买或升级单位继承剩余时间的战力鼓舞。

已知问题：原版历史年表不会可靠自动弹出，当前以授赏卷轴显示本次时代分；镜头距离和聚焦仍有优化空间，暂用固定检阅镜头；三维城市模型仍显示。当前版本不宣称这些问题已解决。

源码：Source/MilitaryParade/MilitaryParade.sln；音频和图像源文件、构建工具、许可证随源码保留。CREDITS.txt提供署名。

发行前检查在Linux中进行，不等同于Windows ModBuddy或文明6实机测试。此版没有增加新玩法。
