# 阅兵 · Military Parade

《文明VI》首都阅兵Mod · 正式版 **2.0.5**

[Steam创意工坊](https://steamcommunity.com/sharedfiles/filedetails/?id=3829550040) · [B站：穆_如](https://space.bilibili.com/1820224096) · [问题反馈](https://github.com/HuangShengYong-181/Civ6-Capital-Parade/issues)

## 制作初衷

在我看来，阅兵是一件国家大事，也是值得纪念的时刻。我希望在《文明VI》中体验庆贺胜利、光复失地、振奋士气与展示国力的仪式感。没有找到完全符合自己设想的作品，于是决定自己动手制作，并将源码公开，方便交流与改进。

## 主要功能

- 凯旋、光复、振军、强军四类首都阅兵，由战事与军力里程碑触发。
- 首都陆军及符合设施、距离条件的海空部队参加检阅；将军督礼、随机题词、近景镜头与阅兵音乐。
- 强军阅兵邀请友好领袖，礼成后实际交付金币或富余奢侈品；无力赠礼时由主办玩家决定是否允许无礼出席。
- 科技、文化分别结算尤里卡和鼓舞；对应分项没有可用启发时，补偿来宾自身每回合产出1.5倍的科研或文化进度。
- 每位来宾每时代最多领取一次观摩奖励，AI同样适用。
- 礼成后展示来宾赠礼与到账状态；邀请、赠礼与奖励记录随存档保存。

详细玩法见 [工坊说明](Workshop/description_zh_CN.txt)。正式版不包含测试模式、测试按钮或开发作弊入口。

## 安装与兼容

推荐通过上方Steam工坊安装，并在“额外内容”中启用。仅面向单人游戏，推荐《风云变幻》；多人和热座不受支持。不要同时启用多个同GUID版本。

源码仓库用于开发和学习，不要把包含`.git`、文档及额外素材的整个仓库直接作为工坊上传目录。手动安装与上传应使用正式发行包中的`Install/MilitaryParade`。

音乐播放、默认音乐和本地导入工具位于主模组。`Settings/`是独立的可选音乐设置组件，不是主模组的必需依赖。

修改生产面板、市政界面、单位旗帜、历史年表或镜头的其他Mod可能需要兼容适配。

## 源码导览

| 文件或目录 | 用途 |
| --- | --- |
| `Parade_Script.lua` | 游戏事件、礼成与奖励入口 |
| `Parade_Rules.lua` | 资格、参阅规模、外交与赠礼规则 |
| `Parade_Campaign.lua` | 筹备生命周期、检阅移动与读档恢复 |
| `Parade_Diplomacy.lua` | 邀请、赠礼、观摩奖励与领取记录 |
| `Parade_Delegation.lua/xml` | 外交邀请和赠礼汇总界面 |
| `Parade_Celebration.lua/xml` | 检阅与礼成演出 |
| `Parade_Camera.lua`、`Parade_March.lua` | 镜头与参阅单位移动 |
| `Art/`、`Icons/`、`AudioSource/` | 美术、图标与音频源文件 |
| `tools/` | 音乐导入、声音库构建与镜头辅助工具 |
| `MilitaryParade.sln`、`MilitaryParade.civ6proj` | ModBuddy工程 |

核心逻辑使用Lua，规则与文本采用SQL/XML。可使用文明VI SDK中的ModBuddy打开工程；原生资源构建需要相应SDK资源和工具。镜头配置修改、声音库结构和原生API仍需实机验收。

## 存档说明

筹备、邀请、贺礼和领奖记录持久化，读档不应重复发放已结算奖励。中途检阅读档后恢复参阅单位，演出不会从中间续播；尚未查看的赠礼汇总可补显示。

旧开发存档中已经生成的单位、金币或已研究科技不会自动撤销。建议先备份存档，再更新并验证兼容情况。
